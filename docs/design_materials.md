## 一、游戏定位与核心概念

- **游戏名称**：《余烬守夜》（EmbersKeep）
- **核心定位**：一款以怪物素材铸造防御卡牌为核心的单机放置塔防游戏。玩家通过探索、战斗和收集，不断扩充卡牌图鉴，利用战斗中的随机技能构筑不同战术流派，最终守护人类最后的炉火。
- **目标平台**：TapTap（Android 单机精品首发 / iOS）
- **游戏类型**：单机放置塔防 + 卡牌锻造 + Roguelike 技能选择
- **商业化模式**：单机买断制或轻度免广告/DLC内容扩展，无逼氪数值坑。

## 二、世界观与主线剧情

### 1. 核心世界观
- **太阳熄灭**：世界的恒星天穹之炉熄灭，世界陷入永恒极夜与严寒。
- **灰潮降临**：黑暗中涌出无尽名为“灰潮”（Ash Tide）的变异怪物，吞噬一切热量与生命。
- **移动铸炉**：人类最后的幸存者依托古老的炉火结界苟延残喘。玩家扮演一名流浪的“原初铸炉师”，驾驶着一座古老巨大的移动机械铸炉（Mobile Forge）穿越废土。
- **终极使命**：收集散落在世界五大区域的七枚“天穹炉心碎片”（Hearth Core Fragments），重启天穹之炉，驱散永夜。

### 2. 五大主线章节（区域规划）

| 章节 | 区域名称 | 主题与环境 | 核心机制与敌人特征 | 章节目标与产出 |
| :--- | :--- | :--- | :--- | :--- |
| **第一章** | **灰烬边境 (Ashen Frontier)** | 废土荒原、枯木、残垣断壁 | 新手引导。敌人以近战灰狼、低护甲爬行者为主。 | 击败区域Boss“灰狼首领”，获得第1枚炉心碎片，解锁基础弩塔与铸造系统。 |

## 三、核心玩法与系统设计

### 1. 差异化核心：卡牌锻造系统（三合一固定配方）
卡牌并非传统抽卡获得，而是由玩家收集材料亲手铸造：
$$\text{防守卡牌} = \text{基础图纸（基底类型）} + \text{怪物核心（属性/机制特性）} + \text{铭文材料（技能附加）}$$

- **基础图纸**：决定卡牌基础类型（弩箭塔、坚固石墙、火焰祭坛、减速陷阱、高射雷炮等）。
- **怪物核心**：击败特定怪物或 Boss 掉落，决定核心质变效果：
  - 风狼核心 $\rightarrow$ 攻速极大提升、多重散射
  - 雷兽核心 $\rightarrow$ 普攻附带连锁闪电
  - 岩甲巨兽核心 $\rightarrow$ 受击反弹伤害、石化护盾
  - 幼龙核心 $\rightarrow$ 造成范围持续火焰灼烧
  - 毒蝎核心 $\rightarrow$ 剧毒泥淖、范围减速与百分比掉血
- **设计准则**：**配方采用固定可预期设计**，拒绝纯随机开箱。玩家看到心仪的卡牌配方后，有明确的动力去对应关卡猎杀特定怪物。

### 2. 战斗内 Roguelike 技能三选一（单局战术构筑）
- **触发节点**：防守战每抵御 2 波敌人，弹出 3 个随机战斗战术技能供玩家选择。
- **代表性技能**：
  - *余烬回响*：防御塔击杀敌人后产生局部爆炸。
  - *穿云之箭*：所有投射物获得 +1 穿透并提升暴击率。
  - *熔岩之心*：火焰伤害提升 40%，且点燃地面持续灼烧。
  - *钢铁意志*：城墙受到攻击时恢复最大生命值 2%。
  - *雷霆共鸣*：雷电每次连锁伤害不衰减，且概率触发眩晕。
- **四大典型流派联动**：
  1. **穿透弹幕流**：穿云之箭 + 高攻速风狼弩塔 + 弹道分裂
  2. **全屏灼烧流**：熔岩之心 + 火龙祭坛 + 余烬回响连锁爆炸
  3. **连锁闪电流**：雷霆共鸣 + 多重雷兽塔 + 感电易伤
  4. **防守反击流**：钢铁意志 + 岩甲荆棘城墙 + 反弹冲击波

### 3. 闭环生态：怪物即材料库
$$\text{挑战怪物} \xrightarrow{\text{击杀掉落}} \text{怪物核心/素材} \xrightarrow{\text{铸造工房}} \text{定制防守卡牌} \xrightarrow{\text{策略布防}} \text{挑战更高阶怪物}$$

### 4. 放置与挂机循环
- **战前**：搭配 4~6 张防守卡牌，规划摆放站位与防御路线。
- **战中**：全自动索敌与攻击，玩家专注关键波次的 Roguelike 技能抉择。
- **战后**：获取核心材料、炉火能量、金币。
- **离线巡逻**：已通关的主线区域可委派铸炉副手进行离线巡逻，产出基础矿石与金币（设置 12 小时累积上限，禁止离线直接自动推进未通关的主线）。

### 5. 外围永久养成系统
1. **移动铸炉升级**：提升锻造炉阶级，解锁高级图纸与三阶合成槽位。
2. **防线据点拓建**：增加出战卡牌槽位、阵地布置网格与辅助机关。
3. **符文研习（天赋树）**：消耗余烬火种升级全局属性（基础攻速、暴击率、初始炉火结界护盾）。
4. **流浪同伴营地**：营救末世废土中的流浪铁匠、学者、巡林客，入驻铸炉提供被动生产加成与支线剧情。
5. **锻造全图鉴（Codex）**：收集各类核心组合出的变体卡牌，激活图鉴达成羁绊加成。

## 四、美术设计规范与 AI SVG 生产管线

### 1. 美术视觉规范
- **视觉风格**：16-bit 暗黑奇幻像素风（Dark Fantasy 16-bit Pixel Art）。
- **基础规格网格**：
  - 基础图标/材料核心：$32 \times 32\text{ px}$
  - 普通怪物/杂兵：$32 \times 32\text{ px}$ 或 $48 \times 48\text{ px}$
  - 防御塔/建筑卡牌：$48 \times 48\text{ px}$ 或 $64 \times 64\text{ px}$
  - 精英怪物与 Boss：$96 \times 96\text{ px}$ 或更大
- **色盘与视觉语言**：
  - 主色基调：暗灰炭黑（废土黑夜）、铁锈红（金属残骸）、余烬橙黄（炉火希望）、奥术冰蓝（雷电与冰霜）。
  - 轮廓与光影：统一采用 1px 深色描边，固定左上方 $45^\circ$ 主光源。

### 2. 资产格式分工准则
| 资产类型 | 推荐存储/交付格式 | 引擎内运行时方案 | 理由 |
| :--- | :--- | :--- | :--- |
| **卡牌图面、技能图标、怪物核心** | SVG (矢量源码) | 构建时栅格化为最近邻 PNG | 源码级便于 AI 直接生成、代码参数化换色与图鉴批量导出 |
| **角色行走/攻击逐帧动作** | PNG 精灵图 (Spritesheet) | `Sprite2D` / `AnimatedSprite2D` | 逐帧控制精准，避免矢量动画在运行时的多余开销 |
| **环境地块与地形** | PNG 图块集 (Tileset) | `TileMapLayer` | 网格无缝拼接，渲染性能最优 |
| **技能爆炸/火焰特效** | PNG 序列帧 / GPU 粒子 | 帧动画 + 粒子着色器 | 兼顾像素复古感与打击反馈 |

### 3. AI 静态 SVG 生成规范（矩形矩阵法）
AI 产出像素风 SVG 时，采用结构清晰的 `<rect>` 像素块矩阵，开启 `shape-rendering="crispEdges"`，避免模糊平滑路径：
```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 32 32" shape-rendering="crispEdges">
  <!-- 基础基底像素 -->
  <rect x="12" y="5" width="8" height="4" fill="#665044"/>
  <rect x="8" y="9" width="16" height="4" fill="#A77C52"/>
  <rect x="4" y="13" width="24" height="4" fill="#49372F"/>
  <rect x="13" y="17" width="6" height="9" fill="#806044"/>
  <rect x="10" y="26" width="12" height="3" fill="#342B2A"/>
</svg>
```

### 4. 首批概念验证三件套（Pilot Triad）
1. **基础弩塔 (Crossbow Turret)**：$48 \times 48$ / $32 \times 32$，代表防御设施基底。
2. **灰烬狼 (Ashen Wolf)**：$32 \times 32$，代表第一章典型敌方先锋。
3. **雷兽核心 (Thunder Core)**：$32 \times 32$，代表锻造质变材料。
