## 轮次一：游戏主线与核心机制设想

### 用户提问
> 设计一个可以上架taptap的单机放置防守的游戏，有铸造防守卡片选取技能会有意思吗？但是不知道主线是什么

### 助手方案回复精要
1. **游戏命名与概念**：《余烬守夜》（EmbersKeep），单机放置塔防 + 卡牌锻造 + Roguelike 技能选择。
2. **世界观设定**：太阳熄灭，灰潮涌出；玩家扮演流浪铸炉师驾驶移动铸炉穿越废土；终极目标是寻找七枚炉心碎片重新点燃天穹之炉。
3. **卡牌锻造系统**：三合一配方（基础图纸 + 怪物核心 + 铭文材料），固定配方驱动刷怪动力。
4. **局内战术选技能**：每2波3选1技能，组合流派（穿透弹幕流、全屏灼烧流、连锁闪电流、防守反击流）。
5. **主线大地图规划**：五大区域（灰烬边境、锈铁矿坑、沉没钟塔、永冻王庭、天穹之炉）。每区6-8关+精英+Boss+剧情。
6. **放置循环与外围养成**：布置防线 $\rightarrow$ 自动战斗 $\rightarrow$ 选技能 $\rightarrow$ 收集材料 $\rightarrow$ 离线巡逻。铸炉升级、防线升级、符文研究、伙伴收集、全图鉴。
7. **TapTap MVP 首版规模**：3个主线区域，约18关，12种图纸，30+技能。

## 轮次二：像素风格与 AI SVG 美术可行性

### 用户提问
> 哪能用像素风，然后素材用ai画svg出来吗

### 助手方案回复精要
1. **美术风格定调**：16-bit 暗黑奇幻像素风，基准网格 32x32，角色/建筑规范化。
2. **AI SVG 生成可行性**：
   - 方式 A（推荐）：AI 直接生成 `<rect>` 像素块矩阵的 SVG，声明 `shape-rendering="crispEdges"`。便于代码化调色、标准化批处理。
   - 方式 B：位图矢量化（不推荐为主流程，节点杂乱难维护）。
3. **素材格式分工**：
   - SVG：静态图标、卡牌、怪物核心、掉落物、装备。
   - PNG 精灵图：怪物行走、防御塔攻击、爆炸特效、地形图块。
4. **引擎运行适配注意**：Godot / Unity 处理像素时必须开启最近邻滤波（Nearest-neighbor filter），避免次像素模糊；建议在导出或构建管线中栅格化为最近邻采样 PNG。
5. **首版测试三件套**：基础弩塔、灰烬狼、雷兽核心。
