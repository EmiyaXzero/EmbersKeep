# 《余烬裂隙：桌面摸鱼挂机 ARPG》（EmbersRift: Desktop Idle ARPG）设计规格说明书

> **设计日期**：2026-11-15  
> **产品定位**：占屏幕底部约 1/6 的极窄条（Bottom-Strip）横版像素风摸鱼挂机 ARPG  
> **核心体验**：屏幕边缘常驻挂机 + 经典 12 部位装备纸娃娃 + 裂隙方尖碑爆太古史诗金光 + 秘银熔炉心跳强化  
> **版权合规**：所有专有名词、设定、世界观均为 100% 原创暗黑余烬宇宙，杜绝任何第三方商业 IP 侵权风险  
> **承载形式**：纯前端静态 Web 应用（`idle.html`），支持浏览器自适应底栏与独立无边框弹窗小窗，可 100% 直连 GitHub Pages

---

## 一、 用户意图与核心痛点（Intent & Why）

### 1. 传统游戏在工作场景的痛点
- **全屏沉浸与注意力绑架**：传统塔防、ARPG 需要持续盯着屏幕、频繁点击鼠标，在上班、写代码、开会等工作场景下极易被抓包，心智负担过重。
- **正向反馈延迟过长**：纯挂机文字放置游戏缺乏视觉多巴胺，单纯看数字增长缺乏刺激感。

### 2. 《余烬裂隙》的解决方案
- **屏幕边缘寄生（Bottom 1/6）**：常驻于屏幕最下方（高度约 $160\sim180\text{px}$），不遮挡主工作区（IDE、文档、浏览器）。
- **80% 零打扰全自动**：英雄自动寻路、平砍放波、自动聚怪斩杀、自动按规则分解低阶白蓝装，无需任何操作。
- **20% 极致摸鱼多巴胺**：
  - **裂隙金光一闪**：自动消耗裂隙星石，遭遇远古方尖碑并击碎，黑屏微闪 + 通天金色光柱 + 震撼的爆装备音效，瞬间唤醒多巴胺。
  - **原创 12 部位装备库**：普通(白)/优质(蓝)/稀有(紫)/神器(粉)/太古史诗(深金)/永恒神话(彩虹)分级，附带直接增伤、追击附加、技攻与四系元素强化词条。
  - **秘银锻炉（+10 ~ +15）**：挂机赚金币与余烬玄碳，摸鱼时把武器塞进锻炉，享受心跳加速的“金光大成”或“碎成虚空晶屑”的刺激体验。
  - **一键老板键（伪装模式）**：按 `Esc` 或 `~` 键，游戏瞬间变身为“Maven 构建日志 / CRM 数据同步进度条”。

## 二、 目标、非目标与反向目标（Goals, Non-Goals, Anti-Goals）

### 1. Goals (核心目标)
1. **纯静态极窄视口自适应**：在 $160\text{px}$ 高度下，长条走廊视口、伤害数字、怪物行动画与 UI 紧凑精致，无裁切、无错位。
2. **原创深度的装备与裂隙循环**：
   - 包含 12 个装备槽位（武器、防具 5 件、首饰 3 件、特殊秘宝 3 件）；
   - 裂隙方尖碑（三阶段受击破碎 -> 裂隙霸主登场 -> 击杀金光爆太古史诗）；
   - 秘银锻炉（+1~+7 100%成功，+8~+10 掉级，+11~+15 碎装备为虚空晶屑）。
3. **极佳的摸鱼友好度**：提供独立小窗弹出模式（`window.open` 极窄无边框长条）与一键老板键伪装。
4. **100% 资产继承与自研代码库融合**：全量复用本项目 `assets/textures/` 中的灰烬狼、爬行者动画与 16 色暗黑调色板。

### 2. Non-Goals (明确不做的功能)
- 不做需要两只手频繁搓招的硬核 ACT 战斗（战斗必须 100% 可托底全自动）。
- 不做联机社交/跨服组队系统（保持轻量单机本地存档，使用 `localStorage`）。
- 第一阶段不强依赖 Electron/Tauri 客户端（优先跑通 Web 网页端全平台免安装，后续可平滑套壳）。

### 3. Anti-Goals (严厉禁止的反向设计)
- **严禁全屏弹窗打断**：挂机出史诗时只能用柔和的金光音效和视口光柱提示，严禁弹出遮挡工作的大弹窗。
- **严禁复杂的长文本阅读**：装备对比只看最核心的“战力变动 $\pm$、元素属强、词条”，3 秒内即可决策换装或分解。

## 三、 候选方案权衡（Approaches Considered）

| 方案 | 形态 | 优点 | 缺点 / 权衡 | 决策 |
| :--- | :--- | :--- | :--- | :--- |
| **方案 1：纯桌面客户端（Tauri/Electron）** | 独立桌面程序，置顶悬浮 | 原生吸附屏幕底部，支持鼠标穿透 | 需要针对 Mac/Win 分别打包编译，评委无法点开网页直接体验 | 舍弃（后续扩展） |
| **方案 2：纯网页固定大窗模式** | 常规网页居中显示 | 开发最简单 | 无法体验“贴着屏幕底部一边写代码一边挂机”的桌面摸鱼快感 | 舍弃 |
| **方案 3：网页底栏响应式 + 独立长条小窗（选中方案）** | 纯 Web 应用（`idle.html`），默认底部自适应贴边，支持一键呼出 1920×160 独立长条小窗 | **免安装、全平台秒开、即推即上 GitHub Pages，同时通过独立小窗实现真正的贴底摸鱼** | 无法做到系统全局穿透，但依靠小窗置底或手动摆放已足够好用 | **采纳** |

## 四、 详细玩法与系统机制

### 1. 视口布局（高度约 $160\text{px}$）

```
+---------------------------------------------------------------------------------------------------------------+
| [流浪剑士 自动挥砍] [狼群与爬行者] [伤害浮字 -8942] [裂隙方尖碑] | [勇士头像] [裂隙星石: 48/20] | [背包(12部位)] [秘银熔炉] |
| ====== 55% 宽度：横版长条战斗视口 (Canvas 2D) ====== | = 20% 宽度：仪表盘 = | = 25% 宽度：摸鱼操作抽屉 = |
+---------------------------------------------------------------------------------------------------------------+
```

### 2. 核心数值与 12 部位装备体系（原创暗黑体系）

#### ① 12 大装备部位
- **武器（5大流派）**：
  - 流光太刀（攻速暴击）
  - 破峰巨剑（超高物理直接伤害）
  - 虚空短剑（奥术魔法技攻）
  - 疾风光剑（高频连击附加）
  - 重型破甲锤（眩晕碎甲）
- **防具（5件套）**：战盔、胸甲、护胫腿甲、战带、战靴（提供力量/敏捷、HP上限、移动攻速）。
- **首饰（3件套）**：护腕、灵符项链、符文指环（提供四系元素强化：火/冰/雷/暗，以及暴击率）。
- **特殊秘宝（3件套）**：左槽战神徽章（直接物攻/魔攻面板加成）、右槽混沌魔石（全元素属强加成）、灵犀耳坠（终极追击增伤）。

#### ② 装备品阶与掉落光效
- **普通（白）**：分解产物少量金币。
- **优质（蓝）**：分解产物金币 + 精铁矿。
- **稀有（紫）**：分解产物金币 + 余烬玄碳。
- **神器（粉）**：低概率世界掉落，带有专属特效词条。
- **太古史诗（深金色）**：裂隙方尖碑专属掉落！**落地触发震撼的金色通天光柱与大地震颤音效**。
- **永恒神话（彩虹炫光）**：极低概率破界大彩蛋，单角色仅可佩戴 1 件。

#### ③ 秘银锻炉（Mithril Forge）
- **消耗**：金币 + 余烬玄碳（挂机产出）。
- **机制与风险**：
  - `+1 ~ +7`：100% 成功，武器散发微弱白光；
  - `+8 ~ +10`：失败掉级（掉回 +6 / +7），武器散发蓝光/紫光；
  - `+11 ~ +12`：成功散发粉红色/金光，**失败装备直接破碎，返还大量“虚空晶屑”**；
  - `+13 及以上`：全服级金色闪光，毁天灭地的攻击力加成！

### 3. 裂隙破界（Rift Event）战斗流
1. 挂机斩杀普通怪掉落【裂隙星石】；
2. 裂隙星石累积达到 20 颗时，战场正前方刷出古老**裂隙方尖碑**；
3. 英雄击打石碑（三阶段受损变红裂开）；
4. 石碑碎裂，唤醒出裂隙霸主（灰烬狼王 / 虚空爬行巨兽）；
5. 斩杀首领瞬间，**屏幕震颤，金色光柱拔地而起，爆出闪闪发光的太古史诗装备**！

### 4. 摸鱼专精：老板键（Boss Key）
- 按下键盘快捷键 `Esc` 或 `~`（或点击右侧小图标）：
- 游戏画面瞬间隐藏，平滑替换为绿色等宽字体的终端仿真界面：
  ```text
  [INFO] 2026-11-15 17:45:01 [Worker-8] Fetching CRM customer sync batch #4092... OK
  [INFO] 2026-11-15 17:45:03 [Worker-8] Analyzing 128 data frames... 100% processed.
  [BUILD] Compiling dependency artifacts... 48/48 modules verified.
  ```
- 游戏后台继续静默全自动挂机、累加金币与装备，再次按下按键无缝恢复游戏界面！

## 五、 架构与容错设计

#### ① 战斗推进与 Boss 战失败容错（方案 A）
- **永不死亡，挂机零中断**：主角拥有充沛生命值与自动生命回复，在常规挂机小怪层永远不会阵亡；
- **裂隙 Boss 战 60 秒倒计时机制**：方尖碑破碎唤出裂隙霸主后，启动 60 秒战斗计时器：
  - 若在 60 秒内击杀 Boss：触发屏幕微震、金色通天光柱、太古史诗装备爆落与专属音效；
  - 若 60 秒内未击杀 Boss：Boss 狂暴遁走并留下一地保底材料箱（裂隙晶核与金币），角色平滑回到常规长廊继续割草刷经验与门票，确保全天工作挂机进程绝对不卡死中断。

#### ② 窗口形态与极窄视口自适应
- **常规浏览器视口（1920×1080）**：上方 80% 区域呈现暗黑余烬要塞动态背景（低功耗粒子与壁画），底端 160px 固定吸附摸鱼游戏条，提供“放大全屏”与“独立小窗”按钮；
- **独立无边框摸鱼小窗**：点击后通过 `window.open` 弹出极窄窗口（内视口高 160px），自适应紧凑排版，方便拖动吸附在屏幕底部 Dock/任务栏上方；
- **双窗口防多开与状态同步**：使用 `localStorage` 时间戳与主从心跳锁，同一时间仅允许一个活跃战斗模拟器运行，避免并发数据冲突。

#### ③ 后台休眠与定时器节流穿透（Web Worker 引擎）
- 现代浏览器在标签页隐藏或最小化时会将 `requestAnimationFrame` 降至 0 FPS，并将 `setInterval` 节流到 1000ms；
- **解耦架构**：战斗、掉落、伤害判定完全基于独立轻量 `Web Worker` 驱动的纯数值心跳（100ms 一次 tick），Canvas 仅负责从 Worker 接收快照进行插值渲染；
- 在按 `Esc` 开启老板键或切换 IDE 编码时，底层数值计算完全不受浏览器休眠节流影响，稳定 100% 挂机。

#### ④ 纸娃娃与主角视觉资产规范
- **战斗视口**：主角采用高精度暗黑流浪剑士（16 色像素精灵），具备行走、居合斩、拔刀斩、上挑 4 套动作，武器具备强化光效粒子（+10 散发紫气，+12 散发耀眼金光）；
- **纸娃娃装备栏**：在右侧抽屉面板中，呈现 12 部位装备网格环绕流浪剑士立绘剪影的经典布局。

#### ⑤ 自动分解与背包防爆仓规则
- 挂机产出的普通（白）、优质（蓝）装备在掉落 1 秒后自动按预设规则分解为金币与精铁矿；
- 稀有（紫）装备可勾选“自动分解为余烬玄碳”，或保留在 24 格精简背包装备箱中；
- 神器（粉）、太古史诗（深金）、永恒神话（彩虹）装备 100% 入包，并伴随视觉流光提示；背包满时自动暂存至溢出保险箱，永不丢失史诗。

#### ⑥ +11 碎刀兜底与虚空晶屑经济闭环
- **破损保护兜底**：即使身上唯一的武器在 +11 时碎裂，系统会自动无缝生成一把无法分解的初级【粗糙新手铁剑】（提供基础保底攻击力），确保绝不发生卡关无法杀怪的死锁；
- **虚空晶屑用途**：释放高阶秘技消耗，并可在神秘流浪商人处以 100:1 兑换【裂隙星石】，形成完美的经济内循环。

## 六、 实施任务分解建议

1. **Task 1：底部 160px 极窄视口架构与长条地下城滚动引擎 (`idle.html` + `idle/viewport.js`)**
   - 实现横版自适应长条 Canvas 渲染器，支持主角行走、挥砍动画及多层视差暗黑地牢背景循环滚动。
2. **Task 2：后台 Worker 数值战斗机与怪物波次 (`idle/worker.js` + `idle/battle.js`)**
   - 接入现有灰烬狼、爬行者与狼王动画；
   - 自动索敌、攻击判定、浮动暴击伤害数字、自动经验与金币拾取，不受切后台休眠影响。
3. **Task 3：12 部位原创装备库与掉落池 (`idle/equipment.js`)**
   - 12 部位装备数据定义、品阶颜色（白蓝紫粉金）、随机词条生成与战力计算。
4. **Task 4：裂隙方尖碑机制与太古史诗金光视效 (`idle/rift.js`)**
   - 裂隙星石计数、石碑受击破碎、全屏微闪、通天金色光柱粒子与 Web Audio 爆史诗音效。
5. **Task 5：秘银熔炉与背包管理抽屉 (`idle/forge.js` + `idle/ui.js`)**
   - 12 格纸娃娃装备栏、一键分解低阶装备、+1~+15 强化转盘动画与碎刀机制。
6. **Task 6：摸鱼极窄独立弹窗与老板键终端伪装 (`idle/bosskey.js`)**
   - 1920×160 独立小窗弹出控制、`Esc` 键秒切代码构建日志界面。
7. **Task 7：主导航与 GitHub Pages 部署联动**
   - 在主游戏 `index.html` 与 `pixelforge` 导航栏中添加《余烬裂隙》入口，提交部署至 GitHub Pages。
