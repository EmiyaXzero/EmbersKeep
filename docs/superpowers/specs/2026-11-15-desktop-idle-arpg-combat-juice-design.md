# 《余烬裂隙》爽快度与微操打击感升级设计规范 (Direction A Spec)

## 1. 概述与目标

针对当前版本“仅有骨架数值 Demo、画面枯燥缺乏多巴胺”的核心痛点，本规范落地**方案 1：Canvas 原生粒子与物理喷装引擎**。
通过地面物理彩色喷装、三大主动神技（支持手动微操与全自动巡航）、暴击震屏与顿挫打击感，将极简桌面底部长条打造成既能安心挂机摸鱼、又能时不时按键爆爽的现代暗黑 ARPG。

---

## 2. 三大主动神技体系 (Active Skill System)

在 [`src/idle/battle_engine.js`](file:///Volumes/extpan/souceCode/EmbersKeep/src/idle/battle_engine.js) 中新增角色技能状态机与冷却计时器：

| 快捷键 | 技能名称 | 冷却时间 | 伤害倍率 | 特效与范围表现 | 战术定位 |
| :---: | :--- | :---: | :---: | :--- | :--- |
| **`[Q]`** | **极·拔刀斩 (Draw Sword Slash)** | 8秒 | 350% 攻击力 | 前方微顿 0.15s，斩出一道贯穿视口全长（800px+）的巨大银白月弧剑气，击中所有小怪必定产生击退 | 瞬间清屏、远程消耗 |
| **`[W]`** | **虚空裂地斩 (Void Earthshaker)** | 14秒 | 480% 攻击力 | 英雄腾空跃起 40px 后猛砸地面，激荡起 3 道暗红虚空地裂尖刺与碎石，连续打击 3 次并使怪物减速 50% | 聚怪重创、群伤暴击 |
| **`[E]`** | **觉醒·剑刃风暴 (Blade Tempest)** | 28秒 | 960% 攻击力 (16段) | 英雄化身无敌残影突入敌群，伴随金红交错的极速残影连斩 16 刀，末段触发冲天雷爆与 5px 屏幕震颤 | 霸主决战、绝地斩杀 |

### 2.1 微操模式与自动巡航双轨切换
* **手动模式**：玩家可直接按键盘按键 `Q` / `W` / `E` 或鼠标点击 HUD 技能卡牌释放；
* **自动巡航模式 (`autoCastSkills: true`)**：底栏提供 `[⚡ 自动施法]` 开关（默认勾选），挂机摸鱼时冷却完毕即自动判定优先释放，无需分心。

## 3. 暗黑/DNF 物理地面喷装系统 (Ground Drop System)

### 3.1 抛物线掉落与地面弹跳
* 小怪死亡或 Boss 炸裂时，掉落物（金币、玄碳、装备）不再直接塞入背包，而是生成带有物理属性的 `GroundDrop` 实体：
  - **初始速度**：$v_x = \text{random}(-120, 180)$，重力加速度 $g = 800$，初始向上跃起 $v_y = \text{random}(-280, -180)$；
  - **地面弹跳**：落到走廊地面（$Y = 120\text{px}$）时衰减弹跳 2 次（反弹系数 $0.4$），随后静止停在地面。
* **光柱与品质标签**：
  - 掉落物地面上方渲染竖向微光光柱（普通白 / 精良蓝 / 稀有紫 / 太古史诗冲天金柱）；
  - 头顶显示半透明像素文字框标签（如 `[太古·诛戮太刀]`、`[🪙 +340]`、`[🔥 玄碳 x2]`）。

### 3.2 自动磁吸入包 (Magnetic Pickup)
* 当掉落物着地静止超过 0.6 秒，或英雄靠近至 100px 距离时，自动触发磁吸飞行动画：
  - 物品化为微光粒子加速飞入英雄胸口；
  - 触发 Web Audio 清脆金币/晶石拾取音效，头顶弹起淡金色拾取浮字；
  - 正式将物品数值写入 `player.wallet` 与 `player.inventory`。

## 4. 视觉冲击力与打击感润色 (Visual Juice)

在 [`src/idle/viewport.js`](file:///Volumes/extpan/souceCode/EmbersKeep/src/idle/viewport.js) 中加入：
1. **屏幕震颤 (Screen Shake)**：
   - 触发暴击时：震幅 2px，持续 80ms；
   - 释放 `W 裂地斩` 与 `E 觉醒剑刃风暴` 时：震幅 4~5px，持续 160ms；
2. **打击顿挫 (Hit Stop)**：
   - 大招命中或击破方尖碑关键帧，帧动画微冻 40ms，赋予物理刀刀入肉的顿挫反馈；
3. **武器流光与挥砍拖尾 (Blade Trail & Glow)**：
   - 英雄挥剑时带出半透明刀光弧线粒子；
   - 强化达到 +10 武器披附粉色呼吸光芒，+12 挥动时留存金色光晕轨迹。

## 5. 模块调整与兼容性保证

* **数值核心**：技能伤害与冷却继续在独立 Web Worker 中模拟，后台标签页挂机不受任何浏览器节流影响；
* **老板键与小窗**：所有特效均严格限制在 Canvas 2D 内绘制，老板键 `Esc` 一键伪装终端时立即清空渲染循环，零穿透、零卡顿；
* **测试验证**：编写 `tests/idle/skill.test.js`，保证 Q/W/E 冷却、伤害倍率、自动施法开关及地面喷装磁吸逻辑 100% 覆盖。
